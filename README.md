# 📚 Fundamentos de Desenvolvimento Web (HTML / CSS)

> **Status do Repositório:** ⏳ *Em desenvolvimento contínuo / Semestre Letivo*

Este repositório reúne os exercícios práticos, atividades e pequenos projetos desenvolvidos ao longo da disciplina de Desenvolvimento Web no **2º semestre** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 🎯 Objetivo

O objetivo deste espaço é documentar minha evolução na construção de páginas web, desde a estruturação básica até a aplicação de estilizações mais avançadas e responsivas. Serve tanto para consulta acadêmica quanto para compor meu portfólio prático de estudos.

---

## 🛠️ Tecnologias e Conceitos Abordados

Neste repositório são trabalhados os seguintes fundamentos:

* **HTML5 Semântico:** Estruturação de páginas utilizando tags apropriadas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, etc.).
* **Elementos de Conteúdo:** Criação e manipulação de listas ordenadas (`<ol>`), listas não ordenadas (`<ul>`), tabelas (`<table>`) e formulários.
* **Navegação e Links:** Links internos entre páginas e hiperlinks externos (`<a>`).
* **Estilização Básica (CSS):** Aplicação inicial de cores e estilos Inline/Internal.
* **Organização e Boas Práticas:** Separação de arquivos e boas estruturas de código para web.
