📌 Sobre o repositório
Este repositório reúne meus estudos, exemplos e exercícios de HTML e CSS, desenvolvidos durante minha formação em desenvolvimento web.

O objetivo é aprender a estruturar páginas com HTML, aplicar estilos com CSS e praticar os fundamentos necessários para criar interfaces organizadas, acessíveis e responsivas. Os arquivos serão adicionados conforme eu avançar no curso.
🎯 Objetivos
- Entender a estrutura de documentos HTML.
- Aprender a utilizar tags semânticas para organizar o conteúdo.
- Estilizar páginas usando CSS.
- Trabalhar com cores, fontes, espaçamentos e layouts.
- Praticar a criação de páginas adaptáveis a diferentes tamanhos de tela.
- Construir uma base para projetos futuros de desenvolvimento front-end.
- Registrar minha evolução como estudante de Análise e Desenvolvimento de Sistemas (ADS).
📚 Conteúdos de estudo
Esta lista serve como roteiro para acompanhar os assuntos estudados e será atualizada conforme novos exercícios forem adicionados.
🧱 HTML — estrutura e conteúdo
- [ ] Estrutura básica de um documento HTML.
- [ ] Tags, elementos e atributos.
- [ ] Títulos, parágrafos, links e imagens.
- [ ] Listas ordenadas e não ordenadas.
- [ ] Tabelas e formulários.
- [ ] Elementos semânticos, como header, main, section, article e footer.
- [ ] Boas práticas de organização e acessibilidade.
🎨 CSS — aparência e layout
- [ ] Formas de aplicar CSS: inline, interno e externo.
- [ ] Seletores, propriedades e valores.
- [ ] Cores, fundos, fontes e textos.
- [ ] Modelo de caixa (box model): margin, padding, border e width.
- [ ] Unidades de medida e dimensionamento.
- [ ] display, position e alinhamento.
- [ ] Flexbox e Grid.
- [ ] Pseudoclasses e pseudoelementos.
- [ ] Responsividade e media queries.
- [ ] Transições e efeitos visuais básicos.
Os itens são um roteiro de aprendizagem. Marque-os conforme estudar e praticar cada conteúdo.

🛠️ Tecnologias e ferramentas
- HTML5: estrutura e significado do conteúdo.
- CSS3: estilos, apresentação e layout.
- Navegador: visualização e testes das páginas.

▶️ Como visualizar os projetos
Como os projetos iniciais utilizam HTML e CSS, normalmente não é necessário instalar dependências.
1. Clone o repositório:
   git clone https://github.com/araujoc-dev/FUNDAMENTOS-HTML.git
2. Entre na pasta:
   cd FUNDAMENTOS-HTML
3. Abra o arquivo index.html no navegador, caso ele exista na pasta do exercício.
4. Para editar os arquivos, abra a pasta no editor de código de sua preferência.
Dica: se o exercício estiver organizado em subpastas, entre na pasta correspondente e abra o HTML daquele projeto.
